# Wastelens
🌱 WasteLens: Food Industry Waste Analysis System

Overview

WasteLens is a data-driven Food Industry Waste Analysis System developed to help food-service businesses track, analyze, and reduce operational food waste through actionable insights.

The system enables restaurants and food-service organizations to monitor waste trends across multiple branches, track key performance indicators (KPIs), and generate analytics-driven reports to support better operational decision-making. WasteLens provides a centralized platform for waste logging, reporting, order tracking, and multi-user management.


Problem Statement

Food-service businesses often face challenges in tracking food waste, identifying waste patterns, and generating consistent operational reports. Lack of centralized monitoring can lead to increased waste, higher operational costs, and inefficient decision-making.

WasteLens addresses this challenge by providing a real-time waste tracking and analytics platform that helps businesses monitor food waste, identify root causes, and make data-driven decisions to reduce waste and improve efficiency.


Key Features

✅ Real-time waste tracking and analytics
✅ KPI dashboards and trend analysis
✅ Multi-branch waste monitoring
✅ Role-based access control (Admin, Manager, Staff)
✅ Waste log management and reporting
✅ Daily order entry and waste-per-order analysis
✅ Interactive reports and CSV export functionality
✅ OTP-based authentication and password reset


Tech Stack

Frontend / UI: Streamlit, Plotly
Backend: Python
Database: MySQL
Libraries: Pandas, bcrypt, smtplib


System Modules

* Dashboard – KPI cards, branch comparisons, waste trends
* Waste Log – Record, edit, and monitor waste entries
* Order Entry – Daily order tracking and waste-per-order metrics
* Reports & Analytics – Interactive charts and business insights
* User Management – Role and access management
* Master Data – Category, item, branch, and waste reason management
* Settings – Email/SMTP configuration for OTP authentication


Skills Demonstrated

Python | SQL | MySQL | Data Analytics | Dashboard Development | Business Intelligence | Data Visualization | KPI Analysis | Problem Solving


Project Outcome

WasteLens provides a scalable and data-driven approach to food waste management, helping organizations improve operational visibility, reduce waste, and make informed business decisions through analytics.
